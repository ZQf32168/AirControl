# AirControl

隔空操控，更自由。

AirControl 是一款 Android 手势控制应用。它使用手机前置摄像头，在本机识别手势，再通过用户开启的无障碍服务执行设定的动作。

当前版本：**1.8.1**（版本代码 40）

正式发布日期：**2026-10-13**

开发者：**ThinkNDo（諗到咩就搞咩）**

联系邮箱：**thinkndo@yeah.net**

## 可以做什么

- 识别拇指向上、拇指向下、张开手掌、握拳和 V 手势。
- 为手势选择上滑、下滑、屏幕中央单击、屏幕中央双击、暂停 / 恢复 AirControl、系统默认语音助手或无动作。
- 通过快捷设置磁贴和运行通知控制服务。
- 在应用内查看运行状态与本机诊断。

滑动和点击作用于当前界面，请先在低风险页面熟悉手势与动作。不同应用可能对同一动作作出不同响应。

## 本地识别与隐私

- 手势识别在本机完成，模型随 APK 提供。
- 摄像头画面仅在内存中用于实时识别，不保存为照片、视频或其他本地文件，也不上传。
- 当前版本不申请网络、网络状态、录音、定位或存储权限。
- 无广告、分析 / 统计、遥测或远程崩溃上报功能。
- 无障碍服务用于执行用户主动触发的动作，不读取聊天内容、不记录键盘输入、不读取剪贴板。
- 用户设置保存在本机，运行诊断暂存在应用进程中，不自动上传。

系统语音助手和其他应用可能自行联网或使用麦克风，其数据处理不属于 AirControl 的处理范围。

## 安装与首次使用

1. 使用 Android 9 或以上系统；不同设备的兼容性可能有所差异。当前版本已在 Redmi Turbo 3 / HyperOS 2 完成功能验收。
2. 下载并核对正式 APK。Android 可能要求为当前浏览器或文件管理器开启“允许安装未知应用”；请确认来源后再操作，安装结束可关闭此项授权。
3. 打开 AirControl，阅读首次告知和协议，明确同意后再申请相机权限。
4. 阅读独立无障碍说明，根据需要到系统设置开启 AirControl 无障碍服务。
5. 确认手势动作设置，点击“开始手势控制”，再切换到其他应用使用。
6. 可通过应用首页、快捷设置磁贴或运行通知停止控制。

同一正式签名的后续版本可按发布说明覆盖升级。如提示签名不一致，请停止安装并核对来源，不要直接卸载原应用；卸载或清除数据会移除本地设置。

摄像头被其他应用占用、系统后台限制、锁屏或持续运行可能影响可用性。长时间使用可能增加耗电和发热；出现异常请停止控制并查看状态。支付、转账、删除或发送等重要操作建议手动确认。
